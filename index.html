Clip-Bot

A personal tool that turns short Twitch clips of streamers who allow clipping into vertical YouTube Shorts for my own channel.

Uses YouTube API Services

What it does

  • Finds popular public clips of streamers who have publicly allowed clipping.
  • Edits them locally into vertical 9:16 videos with subtitles and credits the streamer in the title and description.
  • Uploads the finished videos only to my own YouTube channel and shows my own channel statistics in a local dashboard.

Who can use it

Clip-Bot runs only on my own computer. It is not offered to other people and does not access anyone else's YouTube account.

By using Clip-Bot you agree to the YouTube Terms of Service. Data handling is described in the Privacy Policy; see also the Google Privacy Policy.

Uses YouTube API Services

Clip-Bot uses YouTube API Services. By using Clip-Bot you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

After the account owner signs in with Google, Clip-Bot accesses only the owner's own YouTube channel:

  • uploading videos to the owner's channel (videos.insert),
  • reading the channel's statistics and list of uploaded videos (channels.list, playlistItems.list, videos.list),
  • running public YouTube searches for creators who allow clipping (search.list).

How data is used

The data is used only to upload the owner's videos and to show statistics in a dashboard on the owner's computer. It is not sold, not shared with third parties and not used for advertising or profiling.

How data is stored

All data, including Google OAuth tokens, is stored only locally on the owner's computer. Clip-Bot has no server and no database outside that computer. YouTube API data is refreshed or deleted at least every 30 days.

Cookies and tracking

Clip-Bot and this website do not use cookies, analytics or any tracking.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. Deleting Clip-Bot's token files on the computer removes all stored access; deleting its data folder removes all stored data.
